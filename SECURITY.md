# Security Policy

## Reporting a Vulnerability

Please report security vulnerabilities confidentially through
[GitHub private vulnerability reporting](https://github.com/zama-ai/terraform-coprocessor-modules/security/advisories/new).
Do not open public issues for security vulnerabilities.

Include the affected module and version, reproduction steps, and potential impact
so that we can investigate the report.

## Response Timeline

We aim to acknowledge reports within 48 hours and provide a resolution timeline
within 7 days.
